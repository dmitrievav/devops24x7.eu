Services

Infrastructure as Code & Cloud Architecture

I design and implement cloud infrastructure as code with Terraform, Kubernetes and Helm on AWS and GCP. This includes migrations between clouds and platforms, CI/CD pipelines and observability that is part of the platform design from the start.

Software Development

I develop backend applications, integrations between systems and automation tools in Python and Go. The result is tested code in your repository, with documentation that allows your developers to extend it.

Technical Consulting & Architecture Review

I analyse existing architecture and infrastructure code, identify risks and bottlenecks, and draw up a modernisation plan. While your team implements the plan, I advise it as a consultant.
