# devops24x7.eu

Source of https://devops24x7.eu, the website of Aleksey Dmitriev (freelance software and infrastructure engineer, Munich).

Static HTML in EN, DE and RU. `scripts/build.py` fills in the legal data from repository secrets and GitHub Actions (`.github/workflows/pages.yml`) deploys the result to GitHub Pages.

Font: Inter, SIL Open Font License 1.1 (`assets/fonts/LICENSE.txt`).
