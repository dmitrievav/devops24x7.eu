Infrastructure as Code & Cloud-Architektur

Ich plane und implementiere Cloud-Infrastruktur als Code mit Terraform, Kubernetes und Helm auf AWS und GCP. Dazu gehören Migrationen zwischen Clouds und Plattformen, CI/CD-Pipelines und Observability, die von Anfang an Teil des Plattform-Designs ist.

Softwareentwicklung

Ich entwickle Backend-Anwendungen, Schnittstellen zwischen Systemen und Automatisierungswerkzeuge in Python und Go. Ergebnis ist getesteter Code in Ihrem Repository, mit einer Dokumentation, mit der Ihre Entwickler ihn erweitern können.

Technische Beratung & Architektur-Review

Ich analysiere bestehende Architektur und Infrastruktur-Code, zeige Risiken und Engpässe auf und erstelle einen Modernisierungsplan. Während Ihr Team den Plan umsetzt, berate ich es.
