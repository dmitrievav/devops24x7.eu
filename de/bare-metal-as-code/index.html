Leistungen

Bare Metal für Rechenlasten, die sich in der Cloud nicht rechnen, verwaltet als Code

Wann Sie das brauchen

Datenintensive Lasten mit schnellen lokalen Platten, etwa ML-Experimente, Datenverarbeitung oder Build-Farmen, kosten in der Cloud unverhältnismäßig viel, aber das Team scheut „Hardware“, weil niemand sie reproduzieren kann.

Was Sie bekommen

Einen Cluster auf gemieteten Servern (Hetzner oder vergleichbar), verwaltet als Code: Installation und Bootstrap mit Ansible, RAID und LUKS nach Ihren Anforderungen an die Daten, Zugriff auf Objektspeicher ohne Schlüssel auf den Hosts, eine Prüfung der Verfügbarkeit der benötigten Serverkonfigurationen beim Anbieter, grundlegende Observability. Eine dokumentierte Prozedur für Aufnahme, Entfernung und Neuinstallation eines Nodes sowie eine Anleitung für die Nutzer des Clusters. Übergabe: Ihr Team nimmt den nächsten Node nach der Prozedur selbst auf.

Typische Dauer

Pilot mit 2–3 Nodes: 2–3 Wochen. Ausbau auf rund zehn Nodes und Übergabe: weitere 2–4 Wochen. Schätzung nach einem ersten Gespräch.
